# stimulu

# Gesture-to-Sound Interaction Demonstration Videos

This repository contains the demonstration videos to accompany our manuscript on the **"Illusion of Instrument Presence"**. These videos are provided to help readers directly experience the gesture-to-sound scenarios and understand the participants' unique sonic (acoustic) experiences across different experimental conditions.

## Video Index & Condition Matrix

The repository includes 8 video files (`.mp4`), named according to the following experimental design factors:

* **Action Type (AT):** `A` = Drumming (Discrete) | `B` = Sliding (Continuous)
* **Performer's Movement Amplitude:** `1` = Narrow | `2` = Wide
* **Gesture-Sound Mapping Clarity (MS):** `1` = Strong | `2` = Weak

---

### Condition A: Drumming (Discrete Action)
In the drumming condition, the strong mapping features precise temporal synchrony with instrument-like sounds, while the weak mapping introduces temporal asynchrony (disalignment) while preserving the sound category.

| File Name | Action Type | Movement Amplitude | Mapping Clarity | Key Characteristics |
| :--- | :---: | :---: | :---: | :--- |
| **`output_with_sound_A_1_1.mp4`** | Drumming | Narrow | Strong | Instrument sound, tight temporal synchrony, narrow physical movement. |
| **`output_with_sound_A_1_2.mp4`** | Drumming | Narrow | Weak | Instrument sound, **temporal asynchrony**, narrow physical movement. |
| **`output_with_sound_A_2_1.mp4`** | Drumming | Wide | Strong | Instrument sound, tight temporal synchrony, wide physical movement. |
| **`output_with_sound_A_2_2.mp4`** | Drumming | Wide | Weak | Instrument sound, **temporal asynchrony**, wide physical movement. |

### Condition B: Sliding (Continuous Action)
In the sliding condition, the strong mapping provides continuous, responsive acoustic feedback using instrument-like sounds. The weak mapping completely alters the sound category, replacing it with environmental noise (e.g., ocean waves) and disrupting the parameter mapping.

| File Name | Action Type | Movement Amplitude | Mapping Clarity | Key Characteristics |
| :--- | :---: | :---: | :---: | :--- |
| **`output_with_sound_B_1_1.mp4`** | Sliding | Narrow | Strong | Instrument sound, responsive pitch/volume modulation, narrow movement. |
| **`output_with_sound_B_1_2.mp4`** | Sliding | Narrow | Weak | **Environmental noise (Ocean waves)**, decoupled mapping, narrow movement. |
| **`output_with_sound_B_2_1.mp4`** | Sliding | Wide | Strong | Instrument sound, responsive pitch/volume modulation, wide movement. |
| **`output_with_sound_B_2_2.mp4`** | Sliding | Wide | Weak | **Environmental noise (Ocean waves)**, decoupled mapping, wide movement. |
